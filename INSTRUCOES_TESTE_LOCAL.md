# Instruções para testar o sistema em outra máquina

## Requisitos
- Node.js 18+ instalado
- Acesso a uma pasta local no computador

## Passos
1. Copie a pasta do projeto para a outra máquina.
2. Entre na pasta do projeto.
3. Execute o arquivo abaixo:

### Windows
- Clique em start-local.bat
- O script instala as dependências automaticamente e abre o sistema

### Linux/macOS
- execute: chmod +x start-local.sh
- execute: ./start-local.sh

## Acesso
- Frontend: http://localhost:5175
- Backend: http://localhost:3001
